\# Expense Tracker API



A RESTful Web API built using ASP.NET Core Web API, Entity Framework Core, and SQL Server.



\## Features



\- User CRUD Operations

\- Category CRUD Operations

\- Transaction CRUD Operations

\- Repository Pattern

\- DTO Pattern

\- Dependency Injection

\- Entity Framework Core

\- SQL Server Database

\- Swagger/OpenAPI Testing
